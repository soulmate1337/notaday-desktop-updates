# Notaday Desktop Updates

This repository hosts the release builds of the **Notaday** desktop app for macOS. It contains no source code – only the downloads and the update feed the app uses to keep itself current.

## Download

[**Download Notaday for macOS**](https://github.com/soulmate1337/notaday-desktop-updates/releases/latest/download/Notaday.dmg)

- Requires macOS 14.4 or later
- Runs on Apple Silicon and Intel Macs
- Signed and notarized by Apple

Open the downloaded `.dmg` and drag Notaday into your Applications folder.

## Updates

Notaday checks for new versions on its own and asks before installing them. You can also trigger a check from the menu bar: **Troubleshoot → Check for Updates…**

All versions are listed under [Releases](https://github.com/soulmate1337/notaday-desktop-updates/releases).

## Files in each release

| File | Purpose |
| --- | --- |
| `Notaday.dmg` | Installer for a fresh installation |
| `Notaday.app.tar.gz` | Update package downloaded by the app |
| `latest.json` | Update feed read by the app |
